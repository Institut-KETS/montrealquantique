Content will be maintained through small, reviewable changes once the project repository and faculty review roles are configured.

Contribution workflow

  1. Use the template for a profile, course, event, or news item.
  2. Supply only facts that can be reviewed by the person or responsible faculty delegate.
  3. Run local validation and inspect both builds.
  4. Request factual-owner and faculty editorial review before publication.

LLMs may help format supplied facts. They do not certify facts, decide membership, invent affiliations, or approve publication.
